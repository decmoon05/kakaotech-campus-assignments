# Todo (Vanilla JS)

카테캠 4기 프리코스 1차 과제. Vanilla JS로 만든 Todo 앱.

## 실행

`index.html`을 VSCode Live Server로 열면 됨. 더블클릭으로 열면 localStorage 일부 동작이 제한될 수 있어서 Live Server 권장.

## 파일

- `index.html` 구조
- `style.css` 스타일 (메인 컬러 #672be0)
- `app.js` 동작

## 구현한 것

- [x] CRUD (추가/수정/완료/삭제, 빈 입력 차단)

- [x] 일간 뷰 (이전/다음 날짜 이동, 선택 날짜의 할 일만 표시)

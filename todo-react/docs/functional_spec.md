# 기능 명세 (Functional Spec)

> 1차(Vanilla JS)와 동일한 기능을 React로 옮기는 것. 새 도메인 없음

## 필수 미션

### 1. Todo CRUD
- 입력창 + 추가 버튼으로 새 Todo 생성
- 빈 입력 시 Todo 생성 안 됨, 안내 메시지 노출
- 목록 표시
- 항목별 수정 / 완료 토글 / 삭제
- 완료 항목은 시각적 구분 (취소선)
- 수정 UI는 `prompt()` 대신 인라인 입력창 (`isEditing` 상태로 토글)

### 2. 상태별 필터링
- 탭: 전체 / 진행 중 / 완료
- 현재 선택된 탭은 시각적 구분
- 탭 전환 후 Todo 추가해도 필터 유지

### 3. 일간 뷰
- 화면에 오늘 날짜 표시
- 이전 / 다음 날짜 이동
- 선택된 날짜의 Todo만 표시
- Todo 생성 시 현재 선택된 날짜가 자동 저장

### 4. 로컬스토리지
- 모든 변경사항 → localStorage 자동 저장
- 새로고침 후에도 데이터 유지
- JSON 직렬화/역직렬화
- `useEffect`로 todos 변경 시 자동 저장
- 초기값은 함수형 초기화 `useState(() => ...)` 로 한 번만 읽기

## 도전 미션

### 1. 주간 뷰 (1차에서 이미 구현, 이식)
- 이번 주 월~일 가로 나열
- 이전 / 다음 주차 이동
- 각 날짜 아래 해당 날짜 Todo 개수
- 오늘 날짜 시각적 구분
- 주간 뷰 상태(`weekStartDate`)도 새로고침 후 유지

## 1차에서 가져올 헷갈렸던 포인트 (재발 방지)

1. **일요일=0 함정**: `getDay()`는 일요일 0. 월요일 기준 주차 계산 시 분기 필요
2. **JSON 직렬화**: localStorage는 문자열만. `JSON.stringify` / `JSON.parse` 필수
3. **시간대 버그** (튜터 Ian 지적): `toISOString()`은 UTC 기준 → 한국 시간 자정 근처 어제로 빠짐. **이번엔 로컬 날짜 기준 문자열로** (`getFullYear`, `getMonth`, `getDate` 조합)
4. **render 사이클** (튜터 Ian 지적): React는 상태 바뀌면 자동 재렌더 → 자동 해소
5. **수정 모드**: `replaceWith` 대신 `isEditing` 상태로 같은 위치에 입력창 렌더

## 비기능 요구사항

- 코드는 기능 단위 커밋
- 컴포넌트는 한 파일 한 컴포넌트
- 객체 생성은 함수로 (튜터 Robert 권고: object literal 직접 X)
- props는 구조분해 할당으로 받기
- 변수명/함수명은 역할 명확하게
- 콘솔 에러 0
